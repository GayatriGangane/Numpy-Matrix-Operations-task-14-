# Task 14: NumPy Matrix Operations

## Project Overview

This project demonstrates basic matrix operations using **Python and NumPy**. Two matrices are created using NumPy arrays, and different matrix operations are performed using NumPy's built-in functions.

## Objectives

The main objective of this task is to understand and implement:

* Matrix Addition
* Matrix Subtraction
* Matrix Multiplication
* Matrix Transpose

## Technologies Used

* Python
* NumPy
* Jupyter Notebook



